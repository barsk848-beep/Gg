# Standoff 2 Cheat Menu (ollie build)

## Что внутри
- Плавающая круглая иконка (overlay) для открытия меню
- Меню: Aim Assist (FOV/Smooth), ESP, No Recoil (множитель)
- Нативный модуль с root-хелперами и точками подстановки оффсетов

## Сборка APK
1. Открой папку `Standoff2Cheat` в Android Studio.
2. Дождись синхронизации Gradle.
3. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
4. Установи APK на устройство с root-доступом для полной функциональности.

## Важно
- Для работы поверх игр нужно разрешение "Показ поверх других приложений".
- Реальные оффсеты Standoff 2 заполняются в `app/src/main/cpp/native-lib.cpp`
  после дампа памяти текущей версии игры.
- Без root доступны только UI-переключатели и хранение настроек.
